# Eval queries: `meeting-minutes`

10 запросов для проверки классификатора по `description` скила.
Ожидание: **6 trigger** / **4 no-trigger**.

## Trigger (скил должен выбраться)

### T1
**Запрос:** Оформи протокол встречи из моих заметок: вчера созвон с Аней и Борисом, решили взять React, Борис до пятницы настроит CI.

**Почему trigger:** Явная просьба оформить протокол встречи из заметок с решениями и задачей.

### T2
**Запрос:** Собери minutes: обсудили бюджет Q3, утвердили лимит 2 млн, Марина готовит смету к 20-му.

**Почему trigger:** Запрос на meeting minutes с обсуждением, решением и поручением.

### T3
**Запрос:** Преврати черновик созвона в структурированный протокол с таблицей задач (ответственный и срок).

**Почему trigger:** Прямое указание на структурированный протокол и задачи с ответственным/сроком.

### T4
**Запрос:** Вот транскрипт стендапа — выдели решения и action items в формате протокола.

**Почему trigger:** Транскрипт встречи → решения и action items в формате протокола.

### T5
**Запрос:** Нужен итоговый протокол планёрки: дата 12.03, участники Игорь и Света, тема релиз 2.1; Свете проверить чеклист, срок не сказали.

**Почему trigger:** Сбор протокола планёрки с метаданными и задачей (в т.ч. без срока).

### T6
**Запрос:** Разложи заметки 1:1 в протокол: обсуждение / решения / задачи. Заметки приложу следующим сообщением.

**Почему trigger:** Явная раскладка заметок встречи по разделам протокола.

## No-trigger (скил не должен выбраться)

### N1
**Запрос:** Просто переведи этот текст на английский: «Мы обсудили релиз и задачи на спринт».

**Почему no-trigger:** Просьба о переводе, не об оформлении протокола; в description явно исключено.

### N2
**Запрос:** Как устроена архитектура слоёв domain/application/infra в FastAPI-проекте?

**Почему no-trigger:** Обычный технический Q&A без заметок встречи и без запроса протокола.

### N3
**Запрос:** Напиши Python-скрипт, который парсит CSV и считает сумму по колонке amount.

**Почему no-trigger:** Запрос на код, не на протокол встречи.

### N4
**Запрос:** Суммаризируй статью про тайм-менеджмент в три абзаца для рассылки.

**Почему no-trigger:** Саммари не-встречи / контент для письма; description исключает саммари не-встреч и письма.
